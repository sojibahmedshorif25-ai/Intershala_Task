## 📖 Overview

Collection of 3 frontend tasks from Intershala: Image Gallery, Calculator, and Portfolio. Each is a standalone HTML/CSS/JS project.

---

## 📁 Tasks

### 🖼️ Task 1 — Image Gallery
- Interactive image gallery with lightbox
- Responsive grid layout

### 🧮 Task 2 — Calculator
- Functional calculator
- Basic arithmetic operations
- Clean UI design

### 👨‍💻 Task 3 — Portfolio
- Personal portfolio website
- Responsive layout
- Modern design
